# 二维化天空雾色适配

2026-11-13：二维化演出原先只覆盖天空色和天空亮度，原生雾仍使用环境颜色。现在由 `modules/effect/atmosphere.py` 统一管理雾色，使其随现有环境包络过渡到天空使用的深蓝紫色 RGB `(0.018, 0.012, 0.055)`，结束阶段同步恢复。

进入演出前保存雾色和自定义颜色覆盖开关；最后一轮有效演出结束、离开效果范围、切换维度或客户端清理时恢复。原先有自定义雾色时恢复原值，原先没有覆盖时交回引擎控制。保持原雾色 alpha（SDK 注明它影响水下效果），不调整雾效距离。

本次仅修改 effect 客户端业务、对应离线测试及本文档。既有 `space_collapse_v15.fragment` 未提交修改保留，不纳入本次提交。未修改 nuoyanlib、SDK 或服务端二维化逻辑。
