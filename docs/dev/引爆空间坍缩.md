# 引爆空间坍缩

**当前版本已改为向二向箔输出水平面压缩，见末尾“改为向平面汇拢”。以下向中心点收缩的实现和截图记录为此前版本。**

2026-11-13：用户选择在现有十五秒演出期间持续扭曲、逐渐坍缩，保留天空裂缝。

## 当前实现

- 通过既有 `FoilFieldState` → `EffectServer` → `FoilSpaceFallState` → `FieldPlayback` 接入当前演出，不新增运行时业务监听或跨端消息。仍沿用原有 `moving` 且有目标方块的播放条件，不改变空目标的触发规则。
- 材质切换到 `space_collapse.vertex` 与 `space_collapse_v15.fragment`。新片元中的天空噪声、条纹和裂缝函数与 v14 逐字一致；局部景物部分使用持续十五秒的空间折射。
- 从深度重建可见表面的世界位置，以二向箔中心为固定空间锚点，通过现有半径和柔边椭球遮罩限定局部影响范围。
- 将世界中心投影为屏幕焦点，反向采样远离焦点的景物，使其视觉上向中心收缩，竖向收缩更强。随时间加入向内运动的折射波纹、轻微切向折叠和青紫色散，辅以稀疏应力细线。
- 0～2 秒渐入，0.5～11 秒逐渐加深收缩，11～15 秒释放并恢复。末段同时受原有强度包络约束，不跟随方块搬移进度重播。
- 近相机深度保护、屏幕边缘衰减、邻近采样深度校验和中心在相机背面的剔除限制折射越界。天空走原有独立分支；HUD 和手持近景未见明显扭曲。
- 仍为单 pass、三组 vec4、五处纹理读取；没有增加贴图、粒子、真实实体或方块位置修改。低画质跳过折射采样，仅保留局部明暗与细线表现。

本次只修改项目的效果材质、着色器和显式测试入口。未修改已有 `foil/client.py`、`foil/server.py` 工作区改动、第三方库、原版后处理配置。没有使用缺失的专用 MCP 扫描工具，以本地资源引用与静态检查替代。

- `probe.mcdk_test_collapse_sample(8.0, False)` 与 `probe.mcdk_test_collapse_sample(8.0, True)`：同相位切换折射。为避免干扰对照，此入口清理当前测试碎片粒子。

新增的测试参数保持默认值兼容旧调用；测试入口不在正式游戏流程自动执行。

## 改为向平面汇拢（2026-11-13）

用户要求由向点收缩改为向二向箔所在平面扭曲。现在复用 `shape.x` 传入的二维化输出平面高度：在摄像机相对世界坐标中，以 `surfacePosition.y - planeHeight` 作为有符号距离。反向采样时仅放大这个高度差，保留采样点的世界 X/Z，再投影回屏幕，形成平面上方景物下压、下方景物上抬的视觉效果。平面上的采样点保持原位，折射波纹在平面上归零。实际画面仍受原有柔边范围、深度校验及屏幕边缘保护限制。

移除了屏幕中心点、径向收缩和切向旋转，色散沿当前平面折射方向展开；应力细线也使用到平面的高度差。顶点 shader 不再传递中心点的裁剪坐标。天空函数逐字保持，十五秒时间线、最后四秒恢复、五次纹理读取及原有服务端触发规则保持一致。本轮仅修改两份着色器和本文档，不改动运行时 Python、方块搬移或公共库。

离线验证：原有四组 34 项回归通过；另外验证实际材质引用、天空函数一致性、采样数量，以及多个平面高度与平面上/下/零距离的逆映射、收缩方向和零强度恒等关系。纯数学验证不代表游戏内几何实际移动；MCDK 同机位第 10.8 秒分别关闭/开启折射确认景物按高度汇拢，截图保存在 `.tmp/plane_collapse_20261113/off.jpg` 与 `on.jpg`。

本版 MCDK 正常时钟三轮实播 `completed=3 / passed=3`，每轮停留、退场、通道/粒子清理、环境恢复检查均通过；正常时钟约 11.444 秒的画面另存 `live.jpg`，完整结构化结果为 `live-results.json`。最终错误日志为空，通道关闭、粒子清零，测试摄像机解锁成功。本轮没有运行真实方块搬移、手动投掷、其他设备或多玩家验证。
