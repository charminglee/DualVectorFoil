# 天空裂缝着色器（2026-11-13）

本轮按用户确认采用天空后处理：世界方向固定，仅在天空深度像素绘制裂缝，由地形和写入深度的云层遮挡。主裂缝不再创建序列帧粒子；原图集保留作形态参考，不参与新裂缝绘制。

## 时间线与参数

| 客户端秒数 | 行为 |
| --- | --- |
| 0～2 | 青紫边缘的暗色裂口展开 |
| 2～5 | 裂纹从起裂方向沿天空向外扩散 |
| 5～11 | 整个天空保持裂纹，停留 6 秒 |
| 11～15 | 裂纹、天空色调和环境压暗平滑退出 |
| 15 以后 | 关闭通道，恢复原有天空颜色、亮度与覆盖模式 |

原有地面坍缩、折射、碎片及余烬保持五秒动画。天空使用独立的十五秒生命周期，服务端进度和重复心跳不续期。

- `modules/effect/timeline.py`：纯 Python 时间曲线，仅依赖配置，不导入 SDK。
- `modules/effect/playback.py`：触发时捕获中心上方 38 格相对摄像机的世界方向，此后不随摄像机移动重算。摄像机不可用时以向上方向兜底；切维度立即清理。
- `modules/effect/atmosphere.py`：与着色器共用同一退出包络，最后一轮结束恢复之前的覆盖模式。
- `shaders/dual_vector_foil/glsl/sky_rift_v9.fragment`：连续球面方向上的裂口、裂纹和扩散；不采样旧序列帧，不使用天空盒六面贴图。
- 三组 vec4 依次为 `field=(中心 xyz, 有符号半径)`、`shape=(平面 y, 包络强度, 秒数, 展开加扩散进度)`、`style=(固定方向 xyz, 画质开关)`。展开加扩散进度在 0～2 秒从 0 到 1，在 2～5 秒从 1 到 2，此后保持 2。
- 原有折射、辉光和色散系数固定在 shader 中为 `0.028 / 0.95 / 0.003`；低画质仍跳过折射采样。

本机调试发现：新增第四参数可通过 `GetParameter` 读回，但片元内第四向量输出与自定义方向不符。本轮把数据放回已实测可用的三组 vec4，没有依赖第四组向量。正式资源中不含深度或向量的诊断颜色输出。
