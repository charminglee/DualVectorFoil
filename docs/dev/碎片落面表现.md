# 碎片落面表现

2026-11-13：碎片不再向二向箔中心收缩，而是回落到所在水平面，最终平铺。

- `FieldPlayback.start` 继续保存原始源中心，只把粒子发射器的基准高度设为当前快照的 `plane_y`，与已有平面汇拢特效一致。不同任务使用各自的平面高度。
- `cataclysm_shards` 与使用同一碎片贴图的 `cataclysm_embers` 保留随机 X/Z 散布，移除水平向中心收缩的系数。原有高空回落和低空弧线分别保留，竖直运动在寿命的 75%（3.6 秒）结束，此后高度相对平面为零。
- 面片使用 `direction_z` 与 `custom_direction`，法线从倾斜方向逐渐转为世界向上，落面后不再追随摄像机。参数化旋转在落面时停止；沿用 4.8 秒寿命与原有透明度，平铺后全亮停留约 0.7 秒，最后 0.5 秒淡出。
- 粒子数量、贴图、尺寸、配色和清理机制沿用原设置。改动只涉及客户端特效及其粒子资源，不改变方块搬移和公共库。

## 依赖与资料核对

当前未提供专用架构扫描、引用链扫描或粒子资料检索 MCP 工具。本轮按项目授权使用本地源码和静态搜索替代：`effect.client` → `FieldPlayback` → `CatastropheParticles` → 两组粒子资源；`effect.server` 已在快照中提供 `plane_y`，无需更改跨端事件或服务端。没有执行或声称执行 MCP 扫描。

新增字段依据官方文档核对：

- [Particle Appearance Billboard](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/particlesreference/particlecomponents/minecraftparticle_appearance_billboard?view=minecraft-bedrock-stable)：`direction_z` 使面片朝向指定方向，`custom_direction` 提供该向量。
- [Particle Motion Parametric](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/particlesreference/particlecomponents/minecraftparticle_motion_parametric?view=minecraft-bedrock-stable)：逐帧设置相对位置和旋转角度。

## 离线验证

`test_shard_plane` 对实际 JSON 算式做角度制数学采样，覆盖两组资源、随机值边界和随机种子，验证水平位置不收缩、高度不穿过平面、落面后法线向上且旋转停止、停留时仍可见。该求值器仅覆盖所用算术子集，不代表引擎 Molang 解析验证。

`test_catastrophe_atmosphere` 新增不同源中心高度、正负平面高度和独立任务的发射器落点验证。以上新测试以及相关天空、播放、桥接、库复用回归共 42 项，在 Python 2.7 下分组运行全部通过；运行时修改文件的 Python 2.7 编译、客户端导入边界检查和 `git diff --check` 通过。

额外尝试 Python 3.12 时，既有桥接测试中两项以 `str` 检索二进制内容的检查报类型错误；相同测试在项目目标 Python 2.7 下通过。本轮未修改这些既有检查。

本轮不进行实机测试。面片朝向在网易渲染器中的兼容性与实际画面仍需后续游戏内确认，离线数学测试不代表运行效果证明。
