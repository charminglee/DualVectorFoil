# 引爆扭曲冲击波

2026-11-13：按用户要求，在现有引爆演出中增加沿二向箔所在水平面扩散的背景扭曲波。

- 使用引爆点的世界中心及现有客户端单轮计时，0～1.2 秒向外扩散，0.85 秒起淡出，1.2 秒后偏移严格为零。相较初版传播时间减半，并消除视觉场开场半径渐入对传播速度的影响。最大传播半径复用现有视觉场半径；不改变方块处理范围。
- 波带径向宽度参数由 `2.0 + 半径 × 0.025` 增至 `3.0 + 半径 × 0.04`，垂直软衰减尺度由 2.8 格增至 4 格，兼顾俯视和侧视。通过平面及圆柱的解析交点计算，不做射线步进。摄像机移动不改变波的世界中心。
- 新增部分只改变背景采样位置，不添加颜色、发光、色散或粒子。与现有平面汇拢的 UV 偏移叠加，保留原天空裂缝、汇拢色散和应力线。
- 径向采样位移系数目前为 8.4，单轴 UV 偏移上限为 0.08，均在上一版的 4.2 / 0.04 基础上再翻倍。深度检测限制波只影响交点后方的背景，屏幕边缘渐隐；近景和遮挡边缘有采样保护。低画质同样保留此冲击波。
- 复用现有一 pass、三组 vec4 及播放生命周期，不增加 Python 调用、跨端事件、实体或后处理通道。有效波段最多增加一次深度和一次颜色采样；结束后不执行这两次额外采样。

## 离线验证

- 以本地资源绑定、源码引用和静态依赖检查替代缺失的专用 MCP 扫描/检索工具，没有执行专用 MCP 扫描；未新增 SDK 接口。
- 使用项目 `.tmp/shockwave_20261113/` 内的临时 ModernGL 环境，将引擎 include、输入输出声明适配为桌面 GLSL 330 后，完整顶点/片元着色器在本机 NVIDIA GPU 编译和链接成功。这不验证游戏自身的预处理器和渲染管线。
- 增强版 GPU 浮点读回检查：0、1.2、2.4、3、15 秒偏移为零；前景遮挡和波在摄像机后方时为零；俯视、侧视和摄像机位于波内时有偏移，数值有限且不超过上限。半径设为 20 的俯视探针，在 0.3、0.6、0.9 秒的加权波带半径分别约为 6.68、10.38、15.44，符合向外传播。额外检查开场 0.15、0.3 秒的实际渐入半径，确认速度补偿生效。
- 相同传播半径的 GPU 探针中，增强版 0.6 秒与初版 1.2 秒相比，像素偏移长度之和约为原来的 3.82 倍。该指标仅用于离线强度对比，不代表实际游戏观感提升倍数。
- 现有 `test_space_fall.py`、`test_space_fall_bridge.py`、`test_sky_rift.py`、`test_catastrophe_atmosphere.py` 共 34 项 Python 2.7 离线回归通过。
- 初版证据入口：`.tmp/shockwave_20261113/`；增强版入口：`.tmp/shockwave_boost_20261113/gpu_validate.py`、`gpu-validation.json`。未实机测试，实际观感、游戏着色器兼容性及性能仍待游戏验证。
