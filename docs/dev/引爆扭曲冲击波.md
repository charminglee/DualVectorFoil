# 引爆扭曲冲击波

2026-11-13：按用户要求，在现有引爆演出中增加沿二向箔所在水平面扩散的背景扭曲波。

- 使用引爆点的世界中心及现有客户端单轮计时，0～0.6 秒向外扩散，0.425 秒起淡出，0.6 秒后偏移严格为零，淡入时间为 0.03 秒。消除视觉场开场半径渐入对传播速度的影响。最大传播半径复用现有视觉场半径；不改变方块处理范围。
- 波带径向宽度参数由 `2.0 + 半径 × 0.025` 增至 `3.0 + 半径 × 0.04`，垂直软衰减尺度由 2.8 格增至 4 格，兼顾俯视和侧视。通过平面及圆柱的解析交点计算，不做射线步进。摄像机移动不改变波的世界中心。
- 主、副波纹改变背景采样位置，并增加微弱青白波缘；冲击波本身不添加色散或粒子。与现有平面汇拢的 UV 偏移叠加，保留原天空裂缝、汇拢色散和应力线。
- 径向采样位移系数目前为 16.8，单轴 UV 偏移上限为 0.16，均在上一版的 8.4 / 0.08 基础上再翻倍。深度检测限制波只影响交点后方的背景，屏幕边缘渐隐；近景和遮挡边缘有采样保护。低画质同样保留此冲击波。
- 复用现有一 pass、三组 vec4 及播放生命周期，不增加 Python 调用、跨端事件、实体或后处理通道。有效波段最多增加一次深度和一次颜色采样；结束后不执行这两次额外采样。

- 增强版 GPU 浮点读回检查：0、1.2、2.4、3、15 秒偏移为零；前景遮挡和波在摄像机后方时为零；俯视、侧视和摄像机位于波内时有偏移，数值有限且不超过上限。半径设为 20 的俯视探针，在 0.3、0.6、0.9 秒的加权波带半径分别约为 6.68、10.38、15.44，符合向外传播。额外检查开场 0.15、0.3 秒的实际渐入半径，确认速度补偿生效。
- 相同传播半径的 GPU 探针中，增强版 0.6 秒与初版 1.2 秒相比，像素偏移长度之和约为原来的 3.82 倍。该指标仅用于离线强度对比，不代表实际游戏观感提升倍数。
- 现有 `test_space_fall.py`、`test_space_fall_bridge.py`、`test_sky_rift.py`、`test_catastrophe_atmosphere.py` 共 34 项 Python 2.7 离线回归通过。

## 特效通知后延迟 0.5 秒启动二维化

此前 `_detonate` 在同次调用中捕获调色板、计算映射，进入 `moving` 后才通知特效；大规模计算可能先卡住客户端。现在任务从 `priming` 开始，先通过既有 `FoilFieldState` 本地广播及 effect 转发链路通知客户端，等待 `PRIMING_TICKS = 15` 个服务端脚本 tick（正常每秒 30 tick，即 0.5 秒），再进入 `capturing -> moving -> complete`。

- 预启动不读取调色板、不建立世界适配器、不写入方块，也不建立实体接触索引；同 tick 的任务循环不能绕过等待。
- 各任务分别保存捕获截止 tick，保留并发任务槽位和原维度冷却；原来静止后六秒的等待仍然保留，此延迟发生在引爆特效通知之后。
- 特效提前使用固定中心与任务编号，不依赖尚未知晓的方块数量。进入 `moving` 后沿用既有观看者与客户端任务去重，避免重复播放；原来的迟到观看者补发逻辑保留。
- 捕获失败后按原逻辑重试，不重新等待或重播；空区域也会先播放引爆特效，随后以 `no_blocks` 结束。
- 冲击波本身仍为 0.6 秒，强度和波带参数不变。沿用整个引爆演出的计时，不新增 SDK 调用、事件监听或跨模块实现导入。

本轮使用本地引用链、事件消费者检查及 AST 导入检查替代缺失的专用 MCP 扫描/检索工具。`test_foil_priming.py` 新增 6 项时序回归，覆盖等待边界、普通 tick 调度、并发任务/维度、捕获失败、默认无限预算及空区域。旧发射测试更新为先检查预启动，再在截止 tick 验证捕获；该组使用有限预算停在 `moving`，世界写入由调色板回归覆盖。

共运行 113 项离线检查，110 项通过，3 项既有失败未修改业务行为：`test_final_air_also_selects_blocks_in_sphere` 的再次发射与当前维度冷却冲突；`test_invalid_flight_configuration_does_not_create_or_consume` 的旧飞行配置预期失败；`test_capture_uses_returned_blocks_without_height_clipping` 的测试断言禁止即时搬移时检查区块。三项均在 HEAD 基线副本复现；其中发射测试的原始世界替身缺少 `is_loaded`，基线复核使用同样的有限捕获预算以显露底层断言。相关源码 Python 2.7 编译及端侧检查通过。

证据保存于 `.tmp/priming_20261113/`，包含基线副本、原始及捕获预算对齐后的基线日志、本轮分组测试日志。不做实机测试；离线时序成立不等于实际网络及游戏渲染中已验证冲击波可见。
